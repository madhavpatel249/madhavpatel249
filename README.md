# 🐧 Club Penguin Themed Portfolio

A fun and nostalgic portfolio website themed after Club Penguin, featuring an animated penguin that greets visitors!

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and navigate to `http://localhost:5173`

## 🛠️ Build for Production

To create a production build:

```bash
npm run build
```

The built files will be in the `dist` directory.

To preview the production build:

```bash
npm run preview
```

## 🎨 Features

- **Animated Penguin**: A Club Penguin-inspired character that dances on page load
- **Snow Effects**: Continuous snowfall animation
- **Club Penguin Theme**: Blue gradient background with igloo-style cards
- **Responsive Design**: Works great on desktop and mobile devices
- **Interactive Elements**: Hover effects on cards and badges
